Como manter este painel

  1. Peça “atualiza o painel de governança” ao fim de cada gate — republico no mesmo link, preservando o histórico de versões.
  2. Cada gate concluído gera um artefato próprio (PRD, ADRs, wireflow, plano de testes). O link dele entra na coluna Entregável.
  3. Riscos e decisões são acumulativos: nunca apague uma linha — mude o status para mitigado ou superado.
  4. Nenhum gate avança sem aprovação explícita sua. A cor da régua no topo é a fonte da verdade do estado do projeto.
  5. Arquivo-fonte deste template: templates/painel-governanca.html — copie para cada novo projeto em vez de sobrescrever.
